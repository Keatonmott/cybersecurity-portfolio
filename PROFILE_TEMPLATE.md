## Security engineering projects

- **Cloud IAM and detection.** Audited storage access, IAM permissions, and logging settings in a sample cloud inventory. Correlated key creation with an administrative policy change and documented the evidence an analyst would need to triage it.
- **Application security.** Built a local document API and checked access decisions for owners, other users, and requests with missing identities.
- **AI application security.** Evaluated a retrieval simulator on five synthetic documents and recorded both private-value disclosures and correct answers.
