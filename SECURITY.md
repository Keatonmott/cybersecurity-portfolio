# Security scope

The document API listens on loopback. Its demonstration identity header lets a local caller choose a user. The ownership check assumes production callers would obtain their identity from a verified session.

The cloud audit and detector read local fixtures. The fixtures use synthetic users, events, and documentation IP addresses. The optional Terraform configuration defines AWS resources, so review the plan and account costs before applying it.

Use synthetic documents and canaries when adding evaluation cases. The evidence builder writes the resulting answers to files intended for public review.
